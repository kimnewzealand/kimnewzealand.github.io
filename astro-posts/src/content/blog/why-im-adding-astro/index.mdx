title: "Why I'm Adding Astro for Blog Posts"
description: "How and why I'm using Astro as a lightweight blogging tool alongside Hugo and Quarto."
date: 2026-06-13
---



This blog started as a Hugo site built with the Blackburn theme when I was publishing posts using R. I recently added Quarto for Python based posts. I wanted to explore what other blog posting options were available.

I read about [Astro](https://astro.build) which has some modern theme so I thought I would try this and the [Astro Paper](https://github.com/satnaing/astro-paper) theme.
