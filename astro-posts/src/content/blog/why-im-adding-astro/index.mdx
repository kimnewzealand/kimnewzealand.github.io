This blog started as a Hugo site built with the Blackburn theme when I was publishing posts using R. I recently added Quarto for Python based posts. 

I wanted to explore what other blog posting tool options were available for JavaScript type blogs.

I read about [Astro](https://astro.build) which has some modern themes so I thought I would try the [Astro Paper](https://github.com/satnaing/astro-paper) theme.
